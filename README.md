# Library Management System

My third Python programming project!

## About

A beginner-friendly Library Management System developed using Python. This application helps manage books by adding, viewing, searching, borrowing and returning books.

## Features

- Add new books with title and author.
- View all available books.
- Search books by title.
- Borrow books using Book ID.
- Return borrowed books.
- Track book availability.
- Handle invalid menu choices and inputs.

## Technologies Used

- Python
- Python IDLE

## Concepts Used

- Functions
- Lists
- Dictionaries
- Loops
- Conditional statements
- Exception handling
- User input

## How to Run

1. Download `library_management.py`.
2. Open Python IDLE.
3. Open the downloaded Python file.
4. Press F5 to run the program.
5. Select an option from the menu.

## Menu Options

1. Add Book
2. View Books
3. Search Book
4. Borrow Book
5. Return Book
6. Exit

## Note

This version stores book records temporarily in memory. Book records are not permanently saved after closing the program.
